Brand mapping and validation

Brandmaster helps move Fitment Accessory brand review from manual, one-at-a-time research to batch validation against multiple available brand references, with people reviewing the decisions.

Current Brandmaster features

Capabilities for Fitment Accessory brand mapping

Select a feature to see how it supports validation and review.

Batch brand intakeImport Unknown Brand Names from a file or list.Available+

Start from a UBQ-derived CSV, paste one or more names, or prepare a larger worklist. Brandmaster carries the submitted brand ID and original name through review so the final decision stays tied to the right source record.

Multiple validation referencesCheck more than the spelling.Available · sources vary+

Apply name normalization, prior decisions, aliases, available Brand/Root records, ACA and FPA reference data, and enabled local rules. The order and availability of checks depend on workspace setup. Recommendations show which enabled source informed the result.

AI-assisted reviewUse AI as an optional review assistant.Optional · configuration required+

Generate an external validator prompt or, where configured, use the authenticated CoreAI staging connection. Brandmaster checks imported suggestions for safe structure and valid choices. AI suggestions remain proposals; they do not silently change approved brand data.

Human decision reviewInspect, correct, and document each result.Available+

Reviewers can confirm or change a suggested action, mapping ID, or target brand name. They can add evidence and notes, filter or focus the worklist, and keep uncertain or conflicting cases visible for a decision.

Mapping outcomesChoose the appropriate action for each record.Available+

Prepare CREATE, MERGE, SKIP, or DELETE decisions. Merge a known variation such as BMW OE into BMW; create a valid brand that is not represented; correct a typo and recheck it; or mark invalid data for deletion under review safeguards.

Brand CleanupReview existing brand records and proposed changes.Available · deployment-dependent+

Inspect brand cleanup candidates, compare names and aliases, and work through suggested Root updates. Proposed changes remain reviewable so a team member can confirm the edits before they enter the team’s delivery workflow.

Smart CleanupFind cleanup opportunities in brand data.Available+

Run conservative cleanup checks on brand data, identify likely duplicate records and alias conflicts, and prepare suggested changes. The tool surfaces conflicts for a person to resolve rather than choosing an owner automatically.

Brand tables and aliasesInspect and maintain available reference knowledge.Available · workspace-dependent+

Review existing brand information and aliases where the selected deployment and workspace expose those tools. Root records provide canonical targets; ACA and FPA data can provide additional reference matches when loaded and enabled.

Team queue and collaborationShare and coordinate pending brand work.Optional · team service required+

Assign or claim priority items, track their status, coordinate review ownership, and synchronize shared work when the team service is configured. This helps teams see what is waiting and avoid duplicate effort.

Review history and learningReuse approved decisions and see what changed.Available · shared mode varies+

Keep a decision ledger with reviewer activity and outcomes. The learning center helps inspect past decisions and manage reusable validation knowledge, giving later reviews a record to consult.

Progress and data quality viewsUnderstand workload and recurring issues.Some views are local-mode only+

View team throughput and completion progress. In supported local processing mode, additional quality analytics summarize duplicates, conflicts, unresolved records, and categories that may need attention.

Brand enrichmentGather context for selected brand records.Local processing mode+

In supported local processing mode, review evidence and proposed name or alias improvements for selected records. Enrichment supports investigation; proposed changes still need a person to review them.

Data sources and artifactsManage the files and references used by a workspace.Available · workspace-dependent+

Inspect imported source files and generated work artifacts, and configure which reference information is available to a validation run. This helps explain what data was used when a recommendation was made.

Local and offline useContinue working in supported offline setups.Optional · deployment-dependent+

Run selected workflows on a workstation or use a prepared offline site when those options are enabled. Offline and shared-team modes have different available data and tools.

FAQ

Common questions

What is an Unknown Brand Name?+

A brand name from the Fitment Accessory workflow that does not yet have a confirmed mapping in the available brand information.

How does Brandmaster reduce one-at-a-time research?+

It processes a batch of names against the reference data and validation parameters available to the team, then brings recommendations and uncertain cases into a shared review workflow.

What happens when a brand is reviewed?+

A reviewer can map it to an existing brand, create a new brand when it is valid and not already represented, correct a typo and recheck it, or mark bad data for deletion.

Does AI make the final brand decision?+

No. AI can assist with recommendations where configured. People review and approve decisions, especially where records are uncertain or changes affect the catalog.

Does Brandmaster currently update the central Brand table?+

The current workflow prepares reviewed mapping output for the existing upload process. Direct, governed updates to the Brand table are part of the roadmap.

Can other applications use Brandmaster today?+

A shared API for brand lookup, validation, and data retrieval is a future capability. The roadmap is to let approved dependent applications use Brandmaster as a central brand data service.
